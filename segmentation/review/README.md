# Segmentation 검수 도구

설치와 통합 실행은 저장소 루트의 [README](../../README.md)를 참고하세요.
통합 서버에서 `/segmentation/`에 접속하면 마스크 편집·승인·추론·추가 학습을 사용할 수 있습니다.

데이터는 `segmentation/dataset/`, 배포 모델은 `segmentation/models/best.pt`에 있습니다.
브러시·지우개·폴리곤으로 마스크를 수정하고 저장·승인하세요.
데이터셋 생성 시 저장·승인한 라벨을 병합하며 최종 평가 이미지의 소속을 유지합니다.
새 환경에서는 처음부터 학습을 사용하고, 같은 검수 DB의 정책에 연결된 모델은 이어 학습할 수 있습니다.
